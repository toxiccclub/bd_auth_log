# User Authentication System

Простой и безопасный проект на Python для регистрации и аутентификации пользователей с использованием **PostgreSQL**.  
Для хэширования паролей применяется **Argon2** — современный и надёжный алгоритм с солью и настраиваемыми параметрами. Все SQL-запросы выполняются параметризовано, что предотвращает SQL-инъекции.

---

## 🔹 Ключевые возможности

- Регистрация и вход пользователей через командную строку  
- Безопасное хранение паролей с Argon2 (с солью и параметрами безопасности)  
- Защита от SQL-инъекций — все запросы параметризованы (`%s`)  
- Интерактивное меню; ввод пароля через `getpass` (не отображается в терминале)  
- Лёгкая настройка и запуск

---

## 🛠 Установка и настройка

### 1. Клонируем репозиторий

```bash
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME
```

### 2. Создаём и активируем виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. Устанавливаем зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройка подключения к PostgreSQL

В файле `auth.py` укажите свои данные:

```python
import getpass

DB_HOST = 'localhost'
DB_NAME = 'testdb'
DB_USER = 'postgres'
DB_PASSWORD = getpass.getpass("Введите пароль БД: ").strip()
```

> Убедитесь, что база данных существует. Если нет — создайте её в `psql` или pgAdmin:

```sql
CREATE DATABASE testdb;
```

---

## 🚀 Запуск

```bash
python auth.py
```

Появится меню:

```
Выберите действие:
1 - Регистрация
2 - Вход
3 - Выход
```

- **Регистрация** — ввод логина и пароля (пароль скрыт при вводе).  
- **Вход** — проверка логина и пароля.  
- **Выход** — завершение программы.

---

## 🔒 Безопасность

- **Argon2** для хэширования паролей с солью, безопасными параметрами памяти, времени и параллельности.  
- **SQL-инъекции исключены** благодаря параметризованным запросам (`%s`).  
- Пароли не хранятся в открытом виде.  
- Рекомендуется хранить секреты через `.env` или переменные окружения.
