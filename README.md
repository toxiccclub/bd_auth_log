# User Authentication System

Простой и безопасный проект на Python для регистрации и аутентификации пользователей с использованием PostgreSQL.  
Использует **Argon2** для хэширования паролей с солью и итерациями и обеспечивает защиту от SQL-инъекций.

---

## 🔹 Особенности проекта

- Регистрация и вход пользователей через командную строку  
- Безопасное хранение паролей с Argon2 (с солью и параметрами безопасности)  
- Защита от SQL-инъекций через параметризованные запросы  
- Интерактивное меню с безопасным вводом пароля (`getpass`)  
- Простая настройка и использование  

---

## 🛠 Установка и настройка

### 1. Клонируем репозиторий:

```bash
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME
#### 2. Создаём и активируем виртуальное окружение:
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate
```bash

### 3. Устанавливаем зависимости:
```bash
pip install -r requirements.txt
```bash

### 4. Настраиваем подключение к базе PostgreSQL:
В файле auth.py укажи свои данные:

```python
DB_HOST = 'HOST'
DB_NAME = 'NAME'        # имя вашей базы данных
DB_USER = 'USER'       # пользователь PostgreSQL
DB_PASSWORD = getpass.getpass("Введите пароль БД: ").strip()  # пароль
```python
Убедись, что база данных существует. Если нет, создай её через psql или pgAdmin:

```sql
CREATE DATABASE testdb;
```sql

## 🚀 Использование
Запуск скрипта:

```bash
python auth.py
```bash

### После запуска появится интерактивное меню:
Копировать код
Выберите действие:
1 - Регистрация
2 - Вход
3 - Выход
Регистрация: ввод логина и пароля, пароль хранится безопасно.

Вход: ввод логина и пароля для аутентификации.

Выход: завершение работы программы.

Пароли вводятся с помощью getpass, поэтому они не отображаются в терминале.

##🔒 Безопасность
Пароли не хранятся в открытом виде — только безопасный хэш с солью (Argon2).

SQL-инъекции исключены через параметризованные запросы (%s).

Argon2 использует настраиваемые параметры времени, памяти и параллельности для защиты от brute-force атак.
